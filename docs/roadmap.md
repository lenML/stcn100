# 路线图

## 阶段 0：调研

状态：完成首轮。

- ASD-STE100 Issue 9 规则结构与自动化边界。
- 中文标点、数字、文献、术语和科技文档规则。
- textlint、Vale、remark-lint、markdownlint 等工具架构。
- 版权与仓库数据边界。

## 阶段 1：MVP

状态：进行中。

- pnpm TypeScript workspace。
- Core 规则协议、配置预设、诊断和修复。
- Markdown/纯文本基础解析和保护区。
- 通用与 coding 规则包。
- CLI、JSON/text 输出、退出码。
- 单元测试和 CLI 集成测试。

## 阶段 2：解析与规则补强

- Markdown AST，保留原始字符偏移。
- 标题层级、列表平行结构、表格单元格。
- 中文标点宽度、成对符号、异常空格。
- 数字、日期、范围和单位一致性。
- 段落句数统计。
- 行级启用/禁用指令。
- 文件级和项目级术语配置。

## 阶段 3：扩展系统

- JS/TS 配置。
- 外部规则包加载和名称空间。
- 自定义解析器。
- 严格、推荐、迁移三套预设。
- JSON Schema 和配置校验。
- 规则文档自动生成。

## 阶段 4：工程集成

- GitHub Actions 示例。
- 文本编辑器扩展。
- VS Code 扩展和 LSP。
- 基线文件与增量检查。
- SARIF 输出。
- 跨文件术语、缩写、链接和引用索引。

## 阶段 5：规范发布

- 发布稳定的 `stcn100` 规范版本。
- 区分项目自定义规则和外部标准依据。
- 公开可复现评测集。
- 误报率、修复安全性和版本迁移报告。
- 社区规则评审流程。
